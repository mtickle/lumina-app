# Lumina

Lumina is a Progressive Web App (PWA) that delivers an infinite-scrolling, immersive feed of historical and geographical locations. Designed with a modern, mobile-first philosophy, Lumina provides users with bite-sized, visually rich educational cards that feel native on any device.

## Features

*   **Immersive Feed Layout:** A vertical snap-scrolling interface optimized for mobile viewport heights, including dynamic safe-area calculations to prevent system UI overlap.
*   **Glassmorphic Design:** Clean, modern UI elements utilizing Tailwind CSS for beautiful backdrop blurring and clean typography.
*   **Progressive Web App:** Fully installable to mobile home screens with offline caching capabilities, custom SVG/PNG icons, and a native application feel.
*   **AI-Powered Content Engine:** A standalone Node.js background worker fetches foundational data, processes it through Google's Gemini API, and matches it with stunning photography from the Pexels API.
*   **Real-time Data:** Connected directly to Supabase to serve fresh content dynamically as it is generated by the engine.
*   **Deep Dives & Stats:** Interactive modals and drawers allow users to explore locations further or check current feed statistics without losing their place.

## Tech Stack

### Frontend
*   React
*   Vite (with vite-plugin-pwa)
*   Tailwind CSS
*   Lucide React (Icons)

### Backend & Automation
*   Node.js (Lumina Engine)
*   Supabase (PostgreSQL Database & Real-time Subscriptions)

### Integrated APIs
*   Google Gemini API (Content synthesis)
*   Pexels API (Background imagery)
*   API.Bible (Source material)

## Architecture Overview

Lumina is split into two primary components:

1.  **The Client Application:** A lightweight React frontend that focuses entirely on layout, infinite scroll mechanics, and user experience. It subscribes to the Supabase database to populate the feed.
2.  **The Generation Engine:** A headless Node.js worker designed to run on a scheduled cron job. It features built-in network resilience and API failover logic, autonomously generating and pushing new location cards to the database.
